# Инструкция по проверке работы сайта MONROE

## 1. Открываем сайт

Перейдите на:
👉 **[http://localhost:8000](http://localhost:8000)**

Если во всех открытых вкладках браузера сайт все равно сломан — полностью остановите сервисы и перезапустите их:
```
Get-NetTCPConnection -LocalPort 8000,8001,8002,8003,8004 -State Listen | Select-Object -ExpandProperty OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
python run_all.py
```

## 2. Проверяем индикатор вверху (будет зеленым, если БД работает):

```
MySQL DB (monroe_db :3306) ✓
```
(Надпись вверху сайта со строчкой ниже: *«Микросервисная платформа бутика MONROE»* и 4 зеленых точки напротив названий микросервисов).

## 3. Нажимаем кнопки:

1. Перлистируйте слайдер НОВИНКИ ← / → — должны перемещаться мужские и женские новинки.
2. Нажмите **`ДЛЯ НЕГО ⌄`** — должна открыться страница с мужскими товарами («Мужское кашемировое пальто», «Мужские брюки», «Мужские джемперы», «Мужские рубашки», аксессуары).
3. Нажмите **`ДЛЯ НЕЁ ⌄`** — должна открыться страница с женскими товарами.
4. Нажмите на карточку **«Мужское кашемировое пальто»** (в разделе ДЛЯ НЕГО) — должна открыться детальная карточка товара.
5. В детальной карточке нажмите **`ДОБАВИТЬ В КОРЗИНУ`** — товар должен появиться в корзине.
6. Нажмите на сумочку в правом верхнем углу — должна открыться Корзина.
7. Нажмите на человечка в шапке — если вошли как Покупатель (`375445658384` / `123`), откроется Личный кабинет.

## 4. Если не нажимается:

1. Попробуйте `Ctrl + F5` или перезагрузите вкладку браузера.
2. Проверьте в DevTools (F12): вкладка Console — если есть `Uncaught` errors, пожалуйста, скопируйте сюда.
3. Полностью остановите все процессы и перезапустите их (см. команду в п.1).
